Ideally you'll have at least 2 serial ports available - one for CAT and one for debug logging.
If using a posix host, you can always use sockets or pipes.

Set them in the config json below.

Edit config/$profile.config.json to reflect your target.

$profile.config.json
--------------------


Channel memories
----------------

config/radio.channels.json is the reference/default file. For a custom
server build profile, create config/$profile.channels.json if needed.
Debian packaging installs the selected PROFILE's channel file as
/etc/rustyrig/channels.json. If the selected profile has no channel file,
radio.channels.json is installed instead. The client profile's channel
file is not installed as server configuration.
