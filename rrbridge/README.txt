rrbridge
--------

This provides a connector for external media/slicing from SDR.

Currently we provide the following plugins:

	kiwisdr		Online KiwiSDR receivers


Planned plugins:
	websdr		Support for WebSDR.org receivers
	rtl_tcp		Support for rtlsdr via rtl_tcp
	ka9q		Support for ka9q bits

This stuff is quite immature and will likely have bugs. Let me know if you find any.

Please be considerate if using public SDRs, we really don't want to be blocked from using them!
